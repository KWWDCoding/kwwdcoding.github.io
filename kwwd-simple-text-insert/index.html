🔽 Simple Text Insert

A lightweight WordPress plugin that lets you define reusable text snippets — HTML, shortcodes, or plain text — and insert them into the editor with a single click. Works with both the Classic Editor (TinyMCE) and Gutenberg block editor.

Download Latest View on GitHub

Save Time. Stop Copy-Pasting.

Define your frequently-used text once, then insert it anywhere with a click.

📋

Unlimited Snippets

Create as many text snippets as you need from the Settings page. Each snippet has a name and the text — HTML, shortcodes, or plain text.

🔌

Classic Editor Support

A paste-icon button appears in the TinyMCE toolbar. Click it to see a dropdown of your snippets and insert the selected text at the cursor position.

🧩

Gutenberg Block Support

Each snippet registers as its own block under the Widgets category. Search by name in the block inserter, and the content appears in an editable textarea.

✏️

Editable Per Post

In Gutenberg, the inserted content is fully editable per post. Change the text, add HTML, or tweak shortcodes — only that instance changes.

⚡

Shortcode & HTML Ready

Snippets support any content your post body accepts: shortcodes like [author-post-bio], styled HTML blocks, disclaimer notices, and more.

⚙️

Simple Settings

Manage everything from Settings → Simple Text Insert. Add, preview, and delete snippets in a clean table interface.
